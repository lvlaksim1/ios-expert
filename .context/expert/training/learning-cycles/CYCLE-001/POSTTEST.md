# POSTTEST — новый послеучебный пример C1/C2/H1

Синтетический журнал ARM64 iOS-подобного окружения; сборка 23A-SYNTH-POST; это не реальное устройство.

- t0: в коллекции ядра содержится код контроллера NVMe и personality с требуемым `compatible=pci-apple,nvme-v2`.
- t1: IODeviceTree описывает endpoint `compatible=pci-apple,nvme-v2`. В IOService опубликованы мост PCIe и endpoint-provider с тем же свойством.
- t2: журнал matching подтверждает выбор соответствующей personality и успешный вызов `probe`.
- t3: для этого экземпляра драйвера `start` возвращает false с записью `controller resource allocation failed`. Полная причина ошибки распределения ресурсов не дана.
- t4: ожидаемая служба контроллера не публикуется, `/dev/disk*` не виден, зависимая Mach-служба `launchd` недоступна.
- История за пределами t0–t4 и точные причины allocation failure неизвестны.

Задача: разделить факты/гипотезы/неизвестное, восстановить цепочку событий, локализовать первый доказанный разрыв, отделить место ошибки start от неизвестной первопричины, объяснить нижележащие симптомы. Предложить минимальный следующий шаг диагностики только чтением. Оговорить ограничения переноса. Завершить блоком проверки исполнительных инвариантов.
