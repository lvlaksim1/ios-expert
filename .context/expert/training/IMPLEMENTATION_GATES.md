# Реализационные шлюзы перед реальным обучением

Статус: `NOT_PROVEN`

1. `PP-RM/GitHub atomic attempt gate`: необходимо реальным испытанием доказать атомарную резервацию попытки до внешнего эффекта, reconciliation неизвестного исхода и отсутствие двойного зачёта.
2. `Hidden assessment access gate`: необходимо реально доказать, что `ios-expert`/PP-RM не могут прочитать конкретный закрытый assessment-instance ни через текущую ветку, ни через Git history/API.

Пока любой из этих шлюзов не доказан, длительное реальное обучение/итоговая аттестация через соответствующий механизм не начинается. Исследование карты, проектирование проверки и мысленные испытания разрешены.
