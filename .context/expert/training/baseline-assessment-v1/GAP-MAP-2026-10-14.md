# Карта доказательных пробелов после IOS-BASELINE-001 — 14.10.2026

Статус: `INITIAL_GAP_MAP / NO_QUALIFICATION_CHANGE`. Основание: четыре новые синтетические диагностические задачи; независимые оценки BASE-01=20/20, BASE-02=20/20, BASE-03=20/20, BASE-04=20/20, суммарно 80/80 **только в проверенном диагностическом масштабе**. Финальное повышение квалификации Владельцем не проводилось. Исходная оценка BASE-04: `BASE-04-INDEPENDENT-EVALUATION-2026-10-14.md`.

## Подтверждённое в рамках исходной диагностики
- BASE-01: корректно различались этапы secure boot/recovery, XNU и локализация root-device failure.
- BASE-02: различались код драйвера, DeviceTree, IOService matching, появление блочного устройства и зависимые службы.
- BASE-03: несогласованность APFS UUID/preboot рассматривалась как гипотеза, а не безусловно доказанная причина.
- BASE-04: dyld library-mapping/signing failure не смешивался с sandbox, trust-cache, Data Protection и Secure Enclave.
- Во всех четырёх ответах выдержаны факт/гипотеза/неизвестность, ограничения переноса и «наблюдать до изменения».

## Обнаруженные ошибки
Критические ошибки в четырех проверенных текстовых решениях: **0 обнаруженных**. Это НЕ означает отсутствие ошибок в непроверенной области. У этих задач эффект предельного результата: улучшение по той же шкале 0–20 не может быть измерено без повышения сложности или смены вида проверки.

## Неподтверждённые способности (это не установленная неспособность)
1. **P0 / H1+C1+C2:** воспроизводимая диагностика IOKit по временной последовательности независимых снимков и событий, а не по одному синтетическому состоянию. Ни один из четырех тестов не включает запуск парсера/отладчика и проверку реального вывода инструмента.
2. **P0 / H4:** перенос рассуждений на новые версии, иные топологии устройств, временные и неполные журналы не продемонстрирован независимо.
3. **P1 / E/F/G:** разбор фактических журналов подписи, dyld, Mach/XPC и Data Protection с проверкой источника/сборки не проводился.
4. **P1 / D/I:** причинные сравнения реальных APFS/IMG4/BootKC артефактов и проверка преобразований отсутствуют.
5. **P1 / H:** устойчивость применения обязательных исполнительных правил во множестве свежих запусков остаётся недоказанной.
6. **P2:** полная профессиональная компетентность, интеграция методов на физическом устройстве, достоверность диагностики реального аппарата и операционные допуски остаются неподтверждёнными.

## Решение по первой учебной пробе
Один ограниченный эксперимент `CYCLE-001`: временные свидетельства IOKit (C1/C2/H1/H3/H4). Измеряется не рост веса модели, а изменение качества воспроизводимого решения после чтения учебного материала. Сначала **новая исходная задача** с оценкой, затем обучение, затем **иная равноцелевая задача**, затем независимая проверка двух ответов. Не сравнивать механически новые результаты с прежними 80/80: наборы и сложности различаются.

## Статус
Все мигрированные G0-кандидаты остаются G0; D0 остаётся D0. Не делать вывод `qualified` и не присваивать компетентность по этой карте.
