# Исключённое проектное состояние

Ниже перечислены классы данных, намеренно не импортированные как профессиональные ресурсы:

- продуктовая истина конкретного `iOS-Research-Runtime` и её текущие SHA;
- активные IOS-M*/Package* этапы и WAIT_EXTERNAL_EVIDENCE;
- конкретные workflow runs/jobs и их текущий статус;
- PP-RM/OCB/Watchdog/failover/publication решения DEC-0003..DEC-0020, кроме тех случаев, где отдельный технический факт iOS используется лишь как provenance;
- текущие планы и блокеры конкретного продукта;
- менеджерские обязательства, полномочия, проектные решения и owner-directed process rules.

Исключение не означает удаление: всё это сохраняется в исходном Project Manager repository и может использоваться как проектное доказательство при атрибуции конкретного профессионального ресурса.
