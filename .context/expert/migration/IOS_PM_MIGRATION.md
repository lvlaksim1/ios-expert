# Миграция профессионального капитала iOS Project Manager -> ios-expert

Идентификатор: `IOS-PM-TO-EXPERT-2026-10-07-001`
Исходное состояние: `lvlaksim1/iOS-Research-Runtime manager-state@bd55608c6c411e86014f9fbd2feaab999812ca13`
Цель: `lvlaksim1/ios-expert`

## Правило миграции
Создана новая личность `ios-expert`. Личность, полномочия, текущие обязательства и проектная память `ios-research-runtime-project-manager` не переносятся. Из исходного состояния извлекаются только профессионально повторно применимые сведения, методы, кандидаты в навыки, инструменты и эпизоды.

Все импортированные элементы получают G0 независимо от того, насколько сильным было исходное проектное доказательство. Причина: успешная работа отдельного Project Manager не является автоматическим доказательством знания/навыка/компетентности нового Эксперта.

## Перенесённые семейства
1. APFS recovery/root-mount diagnostics и структурное сравнение source/rebuilt APFS.
2. Многоуровневая загрузочная цепочка SPTM/TXM/XNU/recovery/launchd/root shell.
3. Различение наличия Apple PCIe/NVMe/APFS-кода в BootKC и фактического IOService matching/binding.
4. DeviceTree `apcie`, DART/IOMMU, PCIe ranges, provider/class/property dependencies и guest-visible storage path.
5. Метод «сначала расширить наблюдаемость, затем менять семантику».
6. Точное привязывание выводов к версии кода/среды и наблюдаемому end-to-end evidence.
7. Кандидатные сведения о SHA256-primary CodeDirectory для исследовательски модифицированных binaries — только как legacy-unverified кандидат.
8. `qemu-sptm`/Windows Darwin runtime как инструментальный кандидат.

## Не перенесено в профессиональную память
- текущие commit SHA проекта как знания профессии;
- номера workflow/job/package и очередь работ;
- PP-RM, worker A/B, Watchdog, Mailbox, rearm и scheduler mechanics;
- OCB и обходные пути публикации GitHub;
- правила OWNER_GATE и проектная схема полномочий;
- текущий план, blockers и обязательства проекта как задания Эксперту;
- Project Manager identity/authority;
- старые worker ratings, OTK и fenced-worker authority.

Такие элементы могут присутствовать только в provenance конкретного доказательства, если без них нельзя идентифицировать исходный эксперимент.
