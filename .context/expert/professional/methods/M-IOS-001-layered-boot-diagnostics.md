# M-IOS-001 — Послойная локализация загрузочного отказа

Тип: method candidate
Класс: G0

## Процедура-кандидат
1. Зафиксировать точную версию firmware/runtime/build.
2. Определить последнюю наблюдаемую успешно пройденную стадию.
3. Не делать вывод о следующем слое по наличию артефакта предыдущего слоя.
4. Добавить минимальную read-only наблюдаемость на границе слоёв.
5. Локализовать самый ранний отсутствующий observable.
6. Только затем формировать минимальную mutation hypothesis.
7. После изменения заново получить exact-version end-to-end evidence.

## Известные режимы ошибки
- принятие наличия кода за runtime binding;
- принятие одного green marker за полноту системы;
- изменение нескольких слоёв одновременно;
- перенос исторического результата на новый SHA без проверки.

Provenance: APFS reconciliation + PCIe/NVMe boundary work исходного PM.
