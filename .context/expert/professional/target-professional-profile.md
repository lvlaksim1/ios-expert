# Целевой профессиональный профиль iOS-Эксперта

Статус: `DRAFT_FOR_BASELINE_DIAGNOSTICS`
Версия карты профессии: `0.1.0`
Версия профиля: `0.1.0`

## Начальная цель
Проверить, какие из мигрированных способностей действительно принадлежат новому `ios-expert`, а не только историческому Project Manager, и построить доказательную базу для дальнейшего обучения.

## Обязательные действия для первой диагностики
- A1 — локализация стадии загрузочного отказа;
- B1 — APFS/root-mount диагностика;
- C1 — различение наличия кода драйвера и runtime binding;
- C2 — анализ IODeviceTree/IOService evidence;
- D1 — version-bound воспроизводимое доказательство;
- D3 — диагностическое расширение наблюдаемости до мутации.

## Допуск
Для всех действий: D0 до отдельной независимой оценки. Учебные/аналитические действия без внешнего необратимого эффекта допустимы в рамках текущего сервисного мандата, но не считаются D1–D3.

## Доказательства
Нужны новые задачи, не являющиеся простым повторением мигрированных случаев; критерии должны быть определены до попытки. Исторический опыт Project Manager служит источником кандидатов и тестов, но не автоматически доказательством навыка нового Эксперта.
